# Musical Flashbacks

Listen to six anonymous excerpts and put them in the order they were composed.

- **Live:** https://musical-flashbacks.netlify.app
- **Set builder:** https://musical-flashbacks.netlify.app/build
- **Orchestral mode:** https://musical-flashbacks.netlify.app/?mode=orchestral
- **Preview (try changes before they go live):** https://preview--musical-flashbacks.netlify.app

## Project layout

- `site/` — the whole website (static files, no build step)
  - `index.html`, `styles.css`, `app.js` — page and game interface
  - `logic.js` — puzzle rules, scoring, share-link encoding
  - `catalog.js` — Beethoven & Brahms repertoire (Wikimedia Commons recordings)
  - `catalog-orchestral.js` — orchestral works (Apple Music previews)
  - `catalog-library.js` — set-builder library (generated by `tools/build_library.py`)
- `tools/` — scripts that find Apple Music recordings and build the library
- `netlify.toml` — tells Netlify to publish the `site/` folder
- `ROADMAP.md` — ideas and plans

## Running locally

```bash
python3 -m http.server 8765 --directory site
```

Then open http://localhost:8765

The `/build` address needs the Netlify rewrite, so locally use http://localhost:8765/?mode=build.

## Workflow: preview first, then go live

| Branch    | Who sees it | Address |
|-----------|-------------|---------|
| `preview` | just us, for testing | https://preview--musical-flashbacks.netlify.app |
| `main`    | everyone (the live site) | https://musical-flashbacks.netlify.app |

1. Make changes on the `preview` branch and test them locally.
2. Push `preview`. Netlify builds the preview address within about a minute. Try it on the iPad.
3. Repeat until happy. Batch several fixes together.
4. Go live by merging into `main` (one production deploy):

```bash
git switch main && git merge --ff-only preview && git push && git switch preview
```

Share links made on the preview site point at the preview address, so send friends links from the live site.
